# Honig mit echter Bourbon-Vanille (Imkermeister Krüger) – Skripte zum Einsprechen

Grundlage: `TIKTOK_LEARNINGS.md`. Jede Variante = andere Hook-Formel + Dreifach-Hook (Bild + Satz + Text ab Frame 0). Kein Produktname im Hook.

**Fakten vom Etikett (nur die verwenden):** Honig mit echter Bourbon-Vanille · Zutaten: Honig 98,5 %, Bourbon-Vanille 1,5 % · 250 g · Produktionsland Deutschland · Allgäuer Wanderimkerei.
**Nicht sagen:** „gesund“, „zuckerfrei“, „fürs Immunsystem“ o. ä. (Heilversprechen / falsche Aussagen).

**So aufnehmen:** Eine Datei pro Variante, ca. 20–25 s. Locker sprechen. Versprecher → ganzen Satz nochmal.
